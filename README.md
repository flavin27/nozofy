# Kumify
A chrome extension that makes every thumbnail on youtube have nozomi!

This is a fork of Kumify from the great DenzHa24. I'm very grateful for his work and words of encouragement when i contacted him about this project.
I got inspired by DenzHa24, chikenuwu, mrBeastify

DenzHa24: https://github.com/DenzHa24

chikenuwu: https://github.com/IsaacSohn/Sechify 

Mrbeastify: https://github.com/MagicJinn/MrBeastify-Youtube

If anybody wants to help add images to nozofy or help with the code, feel to open a pull request. Please note that the size of the images should be 1280x720 with a transparent background. Of course your name will be added to the credits.
